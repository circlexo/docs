# AGENTS.md

Guidance for AI coding agents (Claude Code, Codex, Cursor and others) working in this repository.

- This repository is documentation only (Markdown). The code is in
  [circlexo/apps](https://github.com/circlexo/apps), which includes this repository as the `docs/`
  submodule.
- Document released behaviour only. Plans and design notes belong in `circlexo/apps/design/`.
- Write plain, short sentences. Use relative links between pages; CI checks them.
- Never commit secrets, personal data, real hostnames or IP addresses. Use RFC 5737 addresses
  (`203.0.113.x`) and `example.com` in examples.
- Contribution rules and the DCO sign-off are in [CONTRIBUTING.md](CONTRIBUTING.md).
